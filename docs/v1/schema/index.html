v1 JSON Schemas

Eleven entity schemas plus shared definitions, executable-encoding, and naming-profile contracts. Each validates JSON-LD records that bind to https://obligationfirst.org/v1/context.jsonld.

  • common.schema.json Shared v0.6 reference, provenance, lifecycle, actor, remedy, and binding-basis definitions
  • authority.schema.json of:Authority
  • jurisdiction.schema.json of:Jurisdiction
  • party.schema.json of:Party
  • instrument.schema.json of:Instrument (with status, enforcement_status, supersedes, wouldSupersede)
  • term.schema.json of:Term
  • obligation.schema.json of:Obligation — Requirement / Restriction / Permission / Reparation (oneOf discriminator)
  • obligation-category.schema.json of:ObligationCategory
  • proceeding.schema.json of:Proceeding
  • allegation.schema.json of:Allegation
  • determination.schema.json of:Determination
  • tombstone.schema.json of:Tombstone
  • executable-encoding.schema.json Polymorphic executable-encoding reference (Catala / Blawx / OpenFisca / others)
  • naming-profile.schema.json Adopter naming and crosswalk profile
