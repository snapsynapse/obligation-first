v1 namespace

Stable URIs for the Obligation-First specification, currently on the v0.6.5 release line. Under the bind-by-major policy the /v1/ namespace serves the entire v0.x→1.x major, so records bound today keep resolving as the spec advances toward 1.0. The v0.6 contract is implemented and published across EveryAILaw, PubLedge, and AI Incident Law. Adopters fetch the context at https://obligationfirst.org/v1/context.jsonld; terms expand under the planned permanent https://w3id.org/of/v1/ vocabulary prefix once the w3id.org redirect is filed.

Worked-example records

Four real record sets round-tripped through the current draft, served as JSON for direct fetch and validation. Every record carries a neutral https://obligationfirst.org/ identifier; where an example corresponds to a real adopter entity, that adopter's published IRI appears only as a crosswalk (via sameAs or anchors), never as the record's own @id. GitHub Pages serves no directory listings, so each link below resolves to one concrete record; browse the rest of a set from its README.
