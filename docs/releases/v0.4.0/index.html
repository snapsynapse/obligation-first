Obligation-First v0.4.0

Defines the .well-known naming-profile format. The naming profile, a Level 2 requirement since v0.3 but previously specified only in prose, becomes a concrete validatable standard: a JSON-LD of:NamingProfile document validated by naming-profile.schema.json, with a flat text/plain provenance sidecar. Additive and non-breaking to adopter records.

  • manifest.json - machine-readable release package manifest
  • sha256.txt - SHA-256 checksum index
  • RELEASE_NOTES-v0.4.0.md - release notes and verification summary
  • /v1/context.jsonld - JSON-LD context
  • /v1/schema/ - JSON Schemas
  • /.well-known/assistant-guide.txt - GuideCheck assistant guide
