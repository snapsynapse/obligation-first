# Obligation-First v0.6.6

Release date: 2026-09-12

This patch updates Undici to 6.28.1 and packages the current v0.6 reference surfaces. The repository release also captures source-bound federation checks merged since v0.6.5: exact relationship-migration admission, explicit unknown assertions, owner-specific committed comparison bases, and pinned history during isolated rebuilds.

Documentation corrections include F14 release status on the namespace page, the missing full-context discovery endpoint, precise version-sync and search-gate instructions, GuideCheck integrity scope, and a schema/JSON-LD-valid synthetic LegalRuleML extension example. The original Colorado snapshot remains byte-preserved beside a separately identified evolution companion that teaches current modeling and unresolved evidence. Existing legal record payloads are unchanged.

The repository tooling now synchronizes current version/date/status summaries, checks expanded documentation parity and executable examples, gates Pages on the canonical search check, rejects invalid release dates/identity, verifies hosted bytes against immutable source, and replays the retained initial/final source-meaning scores. The new checks include deterministic failure cases and make no new model-evaluation or deployed-acceptance claim.

Processed binding handoffs are removed after verified provenance was retained in the adopter kit. Candidate and staged-index guards exclude temporary handoffs from source and commits.

## Compatibility

No record schema shape, context mapping, vocabulary IRI or legal semantic changes. Existing `obligation-first >=0.6.0 <0.7.0` adopter ranges remain compatible. Exact reviewed checker pins remain valid; the new repository release/documentation guard tooling is available from this candidate without requiring a schema or corpus migration. The assistant guide remains on its documented profile 0.2.0 exception.

## Artifact boundary

The generated manifest and SHA-256 list cover the reference artifacts enumerated by `scripts/lib/contract-inventory.mjs`, including schemas, agent surfaces, scope and qualified-time tooling. They do not inventory the whole Git source tree. Operational reconciliation and source-admission checker code remain repository tooling, available from the exact tagged source. OF is private in package metadata and has no npm publication step.

F14 remains offline fixture evaluation. It neither expands production serialization nor establishes legal applicability or Colorado predecessor history. The w3id contribution is prepared but external submission and permanent-IRI resolution remain open.

## Verification

The preparation evidence is recorded separately in `reference/release-preparation-v0.6.6.md`. Publication requires successful checks on the final committed content, an exact tag target, and independent hosted-byte verification. Local preparation does not establish tag, GitHub Release or deployment completion.
