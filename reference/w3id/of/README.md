# Obligation-First

Maintainer: Sam Rogers, PAICE.work PBC, https://paice.work/
Canonical site: https://obligationfirst.org/
Repository: https://github.com/snapsynapse/obligation-first

The existing vocabulary prefix is https://w3id.org/of/v1/. Its term IRIs resolve by 303 redirects to term-specific documentation fragments at https://obligationfirst.org/v1/vocabulary/. Root, context and the explicit schema inventory use 302 redirects to hosted resources. Unknown paths have no redirect rule. There is no content negotiation or new RDF vocabulary in this contribution.

Rules are generated from the repository context and schema inventory by scripts/build-vocabulary.mjs. Local inventory checks run in scripts/test-vocabulary.mjs. Submit only after the destination pages are deployed and verified. This directory is a prepared contribution, not evidence of submission or live w3id service.
